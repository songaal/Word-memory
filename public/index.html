Google Translate

Used for the Korean translation button next to example sentences.

How to get a key
  1. Open Google Cloud Console and pick (or create) a project.
  2. APIs & Services → Library → enable Cloud Translation API. Billing must be on; the first 500,000 characters each month are free.
  3. APIs & Services → Credentials → Create credentials → API key.
  4. Recommended: restrict the key to the Cloud Translation API and to this website.
